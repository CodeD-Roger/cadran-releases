# Cadran — versions publiées

Ce dépôt ne contient **aucun code** : seulement les versions de **Cadran**
(application macOS de suivi du temps) publiées en *releases*, et le fichier
`latest.json` lu par l'application pour se mettre à jour.

Pour installer : ouvrez la dernière *release* et téléchargez le fichier `.dmg`.

Les archives de mise à jour sont signées ; l'application refuse toute archive
dont la signature ne correspond pas à sa clé publique. Avant chaque
publication, un contrôle bloquant vérifie qu'aucun jeton ni aucune clé privée
ne figure dans les fichiers publiés.
